# Maciej Różewicz, Level Design Portfolio

Static site. No build step.

- `index.html`: home page (approach, featured work, other projects, career, about, contact).
- `obversus-umbra.html`: case study of the Dam hub level.
- `assets/css/style.css`, `assets/js/main.js`: style and small scripts (lightbox, nav, scroll reveal).
- `assets/img/ou/`: Obversus: Umbra greybox captures. `assets/img/past/`: earlier projects.

Preview: open `index.html` in a browser.
Hosting: any static host (GitHub Pages, Netlify, Cloudflare Pages). Upload the folder as is.
